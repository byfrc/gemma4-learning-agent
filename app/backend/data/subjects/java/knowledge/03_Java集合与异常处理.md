# Java 集合与异常处理

## 集合
集合是 Java 中存储多个对象的常用工具。常见类型包括 List、Set 和 Map。

## List
List 有顺序、可重复，适合保存按顺序排列的数据，比如学生列表、题目列表。

## Set
Set 不允许重复值，适合做去重，比如统计不重复的用户名或标签。

## Map
Map 用键值对存储数据，适合通过编号查找内容，比如学号对应学生信息。

## 异常处理
异常处理用于处理程序运行中的错误。Java 常用 `try / catch / finally` 来捕获和处理异常。

## 常见错误
- 空指针异常：对象还没创建就被使用。
- 数组越界：访问了不存在的位置。
- 类型转换异常：对象类型不匹配。

## 学习建议
先写出能跑通的集合操作代码，再结合异常处理去理解报错信息，这样比死记 API 更有效。
