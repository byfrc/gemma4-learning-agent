# Java 面向对象基础

## 核心概念
面向对象编程是 Java 学习的核心。你需要先理解“类”和“对象”的区别，再理解封装、继承、多态和接口。

## 类与对象
- 类是模板，描述一类事物的共同特征和行为。
- 对象是类的实例，是可以在程序里真正创建和操作的实体。

## 封装
封装是把数据和操作放在一起，并控制外部对内部状态的访问。常见做法是把成员变量设为私有，再通过 getter 和 setter 访问。

## 继承
继承用于复用已有类的属性和方法。子类可以在父类基础上扩展自己的特性，也可以重写父类方法。

## 多态
多态是“同一个接口，不同的实现”。它让程序在调用时根据实际对象表现出不同的行为。

## 学习建议
如果你能把“类、对象、封装、继承、多态、接口”讲清楚，并且能写出一个学生管理或图书管理的小程序，面向对象这部分就算真正入门了。
