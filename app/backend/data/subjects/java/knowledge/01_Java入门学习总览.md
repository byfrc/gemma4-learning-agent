# Java 入门学习总览

## 适合对象
本资料面向零基础或刚接触 Java 的学习者。你不需要先把所有语法背完，而是应该先理解 Java 的用途、基本语法、面向对象思想，以及如何把一个小程序跑起来。

## Java 是什么
Java 是一种通用编程语言，常用于后端开发、企业应用、Android 生态和各种中大型项目。它强调可读性、跨平台能力和稳定的工程实践。

## 学习主线
建议按下面顺序学习：
1. 基础语法：变量、类型、运算符、条件分支、循环。
2. 面向对象：类、对象、封装、继承、多态、接口。
3. 常用类库：字符串、集合、日期时间、异常处理。
4. 工程工具：IDEA、JDK、Maven、单元测试。
5. 项目实践：控制台小程序、数据管理小程序、Web 入门项目。

## 常见误区
- 只看语法不写代码，很快会忘。
- 只学 Java 语法，不理解面向对象，会卡在项目开发。
- 一上来就学框架，不先掌握基础，会很难看懂报错。
